## 📌 Project Overview
A modern, fully responsive personal portfolio website designed with a **cinematic dark aesthetic**, built to showcase technical proficiencies, academic background, featured engineering productions, and contact channels.

### 🌟 Key Highlights
- **Cinematic Dark Theme:** Inspired by film, motion aesthetics, and creative design with glowing amber, cyan, and violet accents.
- **Strict Adherence to Guidelines:** 100% compliant with HTML5 semantic standards, modern CSS3 styling, and the Bootstrap 5 framework.
- **Interactive Elements:** Dynamic skill category filtering, responsive collapsing navbar, floating back-to-top button, interactive project deep-dive modal, and client-side validated contact form.
- **Fully Responsive:** Tested across mobile (<576px), tablet (768px - 991px), and desktop (1200px+) screen resolutions.

---

## 🛠️ Technologies Used
- **HTML5:** Semantic architecture (`<nav>`, `<header>`, `<section>`, `<article>`, `<footer>`).
- **CSS3:** Custom properties (CSS variables), glassmorphism (`backdrop-filter`), keyframe animations, flexbox & grid layouts.
- **Bootstrap 5.3.3:** Responsive grid system, utilities, modal, and responsive navigation bar.
- **Bootstrap Icons 1.11.3:** Vector icons for technologies, contact channels, and UI controls.
- **JavaScript (ES6+):** Dynamic scroll detection, skill filtering engine, and form validation handler.
- **Google Fonts:** *Space Grotesk* (Display/Headings) & *Plus Jakarta Sans* (Body typography).

## 🚀 How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/chinmay337/assignment-1-webdev.git
   cd assignment-1-webdev/task-1-portfolio
   ```

2. **Open in any modern web browser:**
   - Double click `index.html` or right-click and choose **Open with > Chrome / Edge / Firefox**.
   - Alternatively, serve via Python:
     ```bash
     python -m http.server 3000
     ```
   - Open your browser and navigate to `http://localhost:3000`.
